Employee Details

Employee ID Rule: Only the complete ID is considered duplicate. ASG-316, OIC-316 and ALF-316 are separate employees and adding one will never delete or replace another.

Employee Location can be changed at any time. Use Location Effective Date when moving an employee; previous Location history and records remain saved under the old Location.

Employee ID can be entered manually (for example OIC-316 or ASG-316). Different Employee IDs are stored as separate employees and will not replace or delete each other. If you leave it blank, the system will generate the next ID automatically.
